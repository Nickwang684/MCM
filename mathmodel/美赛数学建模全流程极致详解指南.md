## 1. 赛前准备：构建“O奖”团队基因

### 1.1 角色分工 (Roles)
不要简单地分为“建模、编程、写作”。O奖队伍通常是“全栈”的，但侧重不同：
*   **主攻手 (Lead Modeler):** 数学直觉极强。负责将现实问题转化为数学公式。熟悉微分方程、物理定律。
*   **数据/算法专家 (Data/Algo Specialist):** 编程能力强。负责数据清洗、算法实现（Python/MATLAB）、可视化绘图。
*   **学术主笔 (Lead Writer):** 英语学术写作能力强，逻辑严密。负责**摘要**、背景、结果分析、Memo。**注意：主笔必须懂建模，否则写不出深度。**

### 1.2 工具链 (Toolbox)
*   **写作:** LaTeX (Overleaf) 是必须的。Word 排版在公式和图表混排时会崩溃。
*   **编程:** 
    *   *A题:* MATLAB (ode45, 优化工具箱), Python (SciPy, NumPy).
    *   *C题:* Python (Pandas, Scikit-learn, PyTorch, Statsmodels).
*   **绘图:** 
    *   *示意图:* Visio, Draw.io, PPT (是的，PPT画流程图很快).
    *   *数据图:* Python (Matplotlib, Seaborn), MATLAB, Tableau.
*   **文献:** Google Scholar, arXiv, IEEE Xplore.

## 2. 比赛前 4 小时：黄金选题与破题策略

### 2.1 选题决策 (Decision Making)
不要纠结。浏览所有题目，用 **“数据-机理”二维矩阵** 评估：
*   **A题 (Continuous):** 
    *   *特征:* 涉及物理过程（热、力、流体）、生态动力学（种群、传染病）。
    *   *数据:* 通常不给数据，或给少量参数。需要自己查物理常数。
    *   *门槛:* 需要扎实的微积分和微分方程基础。
    *   *优势:* 只要模型建立正确，结果非常有说服力，容易拿奖。
*   **C题 (Data Insights):**
    *   *特征:* 给定大数据集（Excel/CSV），要求预测、分类、找规律。
    *   *数据:* 题目自带数据。
    *   *门槛:* 需要熟练的数据处理和机器学习技能。
    *   *风险:* 竞争极其激烈，容易陷入“调包侠”的陷阱（只跑模型不讲道理）。

**决策口诀：** 
> “物理好、数学硬，选A题，建方程；”
> “编程溜、统计强，选C题，挖数据。”

### 2.2 破题三部曲 (Problem Restatement)
1.  **逐词翻译 (Translation):** 确保理解 Constraints (限制) 和 Objectives (目标)。
2.  **定义变量 (Variables):** 列出所有 Input (已知量) 和 Output (未知量)。
3.  **画因果图 (Causal Loop):** 在白板上画出系统各要素的相互作用。
    *   *例如 (A题):* 捕食者增加 -> 猎物减少 -> 捕食者饿死 -> 猎物恢复。
    *   *例如 (C题):* 销量受季节影响 -> 受促销影响 -> 受对手价格影响。

## 3. A题 (Continuous) 攻坚手册：从机理到方程

A题的核心是 **“机理 (Mechanism)”**。评委想看你如何用数学语言描述自然规律。

### 3.1 核心模型库
*   **常微分方程 (ODEs):** 
    *   *适用:* 变化率与当前状态有关。
    *   *经典:* 
        *   **Malthus/Logistic 模型:** 种群增长。
        *   **Lotka-Volterra:** 捕食者-猎物，竞争关系（如2024 Lamprey题）。
        *   **SIR/SEIR:** 传染病传播。
        *   **Lanchester:** 战争损耗。
*   **偏微分方程 (PDEs):**
    *   *适用:* 变量不仅随时间变，还随空间变（如热传导、扩散）。
    *   *经典:* 热传导方程 (Heat Equation), 扩散方程 (Diffusion Equation), 纳维-斯托克斯方程 (Navier-Stokes, 流体)。
*   **物理模型:**
    *   牛顿运动定律，能量守恒，基尔霍夫定律。

### 3.2 建模步骤 (Step-by-Step)
1.  **基本假设 (Assumptions):** 
    *   *技巧:* 假设必须是为了简化方程。例如：“假设环境容纳量 $K$ 是常数”。
2.  **列方程 (Formulation):**
    *   写出 $\frac{dX}{dt} = \text{输入} - \text{输出}$。
    *   例如：$\frac{dN}{dt} = rN(1 - \frac{N}{K}) - \beta NP$ (Logistic增长 - 被捕食)。
3.  **参数定标 (Parameter Estimation):**
    *   这是A题最难的地方。数据哪里来？
    *   *方法1:* 查阅文献（引用！）。
    *   *方法2:* 拟合少量已知数据。
    *   *方法3:* 数量级估算 (Fermi Problem)。
4.  **数值求解 (Numerical Solution):**
    *   不要试图求解析解（除非很简单）。
    *   使用 MATLAB `ode45` 或 Python `scipy.integrate.odeint`。
    *   **可视化:** 画出 $X(t)$ 随 $t$ 变化的曲线。

### 3.3 进阶技巧 (O奖加分项)
*   **相平面分析 (Phase Plane Analysis):** 画出 $X$ vs $Y$ 的轨迹，分析稳定点 (Equilibrium Points) 和稳定性 (Stability)。这是数学味道最浓的部分。
*   **引入随机性 (Stochasticity):** 将 ODE 改为 SDE (随机微分方程)，加上噪声项 $\sigma dW_t$，展示系统在干扰下的表现。

## 4. C题 (Data Insights) 攻坚手册：从数据到智慧

C题的核心是 **“洞察 (Insight)”**。评委不想看你堆砌算法，想看你发现了什么规律。

### 4.1 数据预处理 (Data Preprocessing) - 决定上限
*   **缺失值处理:** 插值 (Interpolation)、均值填充、KNN填充。
*   **异常值检测:** $3\sigma$ 原则、箱线图 (Boxplot)、孤立森林 (Isolation Forest)。
*   **数据标准化:** Min-Max 归一化，Z-score 标准化。**不做归一化，后续模型全废。**

### 4.2 核心模型库
*   **预测 (Prediction):**
    *   *短期/简单:* ARIMA (时间序列), 指数平滑。
    *   *长期/复杂:* LSTM (长短期记忆网络), Prophet (Facebook开源), Grey Model (GM(1,1), 小样本)。
    *   *回归:* 多项式回归, Ridge/Lasso 回归 (防止过拟合)。
*   **分类/评价 (Classification/Evaluation):**
    *   *传统:* 逻辑回归, SVM。
    *   *集成学习:* Random Forest (随机森林), XGBoost, LightGBM (Kaggle神器)。
    *   *无监督:* K-Means 聚类, PCA (主成分分析, 降维)。
*   **文本分析 (NLP) (针对如Wordle题):**
    *   TF-IDF, Word2Vec, BERT, 情感分析 (Sentiment Analysis)。

### 4.3 建模步骤 (Step-by-Step)
1.  **特征工程 (Feature Engineering):** 
    *   创造新变量！例如：题目给“每日销量”，你创造“周末效应”、“节假日效应”。
    *   使用 **Correlation Matrix (相关系数矩阵)** 热力图筛选关键特征。
2.  **模型训练与验证:**
    *   **划分数据集:** 训练集 (70%) / 测试集 (30%)。
    *   **交叉验证 (Cross-Validation):** K-Fold 验证，防止过拟合。
3.  **结果解释:**
    *   不要只贴 Accuracy/MSE。
    *   使用 **SHAP values** 或 **Feature Importance** 条形图，解释哪个因素最重要。

## 5. 核心通用模块：O奖论文的“必杀技”

无论A题还是C题，以下两个模块是必须有的，且决定了你是否是O奖。

### 5.1 灵敏度分析 (Sensitivity Analysis)
*   **定义:** 改变模型输入参数，观察输出变化。
*   **目的:** 证明模型“皮实”（Robust）。
*   **操作:**
    *   选定关键参数 $\alpha$。
    *   让 $\alpha$ 变化 $\pm 5\%, \pm 10\%, \pm 20\%$。
    *   画出结果 $Y$ 的变化曲线。
    *   *O奖话术:* "The result varies less than 2% when parameter $\alpha$ changes by 10%, indicating high robustness."

### 5.2 优缺点分析 (Strengths & Weaknesses)
*   **Strengths:** 
    *   考虑全面（Comprehensive factors）。
    *   计算高效（Computationally efficient）。
    *   结合了机理与数据（Hybrid model）。
*   **Weaknesses:** 
    *   数据有限（Limited data）。
    *   假设过于理想化（Idealized assumptions）。
    *   *补救:* "Future work could incorporate..."

## 6. 论文写作 (Writing)：如何征服评委的眼球

### 6.1 摘要 (Abstract) - 生死文书
*   **第一句:** "In this paper, we develop a [Model Name] to address the problem of [Problem Description]."
*   **结构:**
    *   **Problem 1:** "First, we established..." (模型) -> "solved by..." (算法) -> "results show that..." (具体数值结论!).
    *   **Problem 2:** "Second, based on the previous model, we introduced..." -> "finding that..."
    *   **Validation:** "Sensitivity analysis reveals that..."
*   **排版:** 必须在一页内写完。

### 6.2 视觉设计 (Visual Design)
*   **流程图 (Flowchart):** 放在 Introduction 之后，展示整个建模思路。
*   **图表:** 
    *   所有图必须有标题 (Figure 1: ...)。
    *   图注要详细。
    *   多用彩色，但要考虑黑白打印的可读性。

### 6.3 Memo (备忘录)
*   **对象:** 通常是给市长、CEO看的。
*   **风格:** 非技术性 (Non-technical)。不要写公式！
*   **内容:** 
    *   我们发现了什么问题？
    *   我们建议怎么做？
    *   这样做的好处是什么？
    *   风险是什么？
