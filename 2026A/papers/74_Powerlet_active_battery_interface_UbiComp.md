# Powerlet: Active Battery Interface for Smartphones

## 基本信息
- **标题**: Powerlet: An Active Battery Interface for Smartphones
- **会议**: **ACM UbiComp 2014**
- **链接**: https://mobed.yonsei.ac.kr/mobed_pages/pdf/index.php?name=wwjung-ubicomp14

## 研究内容
研究智能手机电池界面的**交互类型**如何影响用户关于**能耗的行为**。

## 与考虑因素的相关性

### 用户行为研究
- **用户意愿**: 用户愿意积极管理电池
- **被动界面无效**: 现有被动界面效果不佳
- **主动界面**: 需要更积极的交互方式

### 电池界面设计
- 交互类型影响行为
- 用户参与程度
- 能耗管理效果

### 行为改变
- 界面设计影响习惯
- 用户参与节能
- 更好的电池管理

## 核心发现
1. 用户愿意管理电池
2. 被动界面无效
3. 需要主动交互设计

## 与论文研究方向的关联
- **用户行为**: 用户与电池交互
- **UbiComp顶会**: 普适计算权威
- **用户建议**: 如何改变用户行为
