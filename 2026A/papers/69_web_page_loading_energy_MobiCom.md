# Rethinking Energy-Performance Trade-Off in Mobile Web Page Loading

## 基本信息
- **标题**: Rethinking Energy-Performance Trade-Off in Mobile Web Page Loading
- **发表日期**: 2015
- **会议**: **ACM MobiCom 2015**
- **链接**: https://www.sigmobile.org/mobicom/2015/papers/p14-buiA.pdf

## 研究内容
研究移动网页加载中的**能耗-性能权衡**，减少能耗而不显著增加加载时间。

## 与考虑因素的相关性

### 网页加载能耗
- **浏览器能耗**: Chromium和Firefox分析
- **网络资源处理**: 资源获取和处理能耗
- **用户体验**: 加载时间影响

### 低效行为识别
1. 低效网络资源处理
2. 频繁进程间通信
3. 不必要的处理

### 优化策略
- 减少能耗
- 保持加载时间
- 改善用户体验

## 核心发现
1. 三种主要低效行为
2. 优化机会识别
3. 能耗-性能平衡

## 与论文研究方向的关联
- **网络活动**: 网页加载能耗
- **MobiCom顶会**: 移动通信权威
- **优化建议**: 浏览器使用优化
