# 184. Mobile Application and Device Power Usage Measurements (NIST)

## 基本信息
- **标题**: Mobile Application and Device Power Usage Measurements
- **机构**: NIST (National Institute of Standards and Technology) / George Mason University
- **年份**: 2012
- **作者**: Rahul Murmuria, Jeffrey Medsger, Angelos Stavrou
- **链接**: https://tsapps.nist.gov/publication/get_pdf.cfm?pub_id=911099

## 核心内容

### 研究背景
- 移动设备功耗优化成为关键设计准则
- 智能手机组件丰富，程序多样
- 需要通用的功耗测量和建模方法

### 研究方法
1. **精确功耗测量**: 硬件级测量
2. **子系统分析**: 各组件功耗表征
3. **模型建立**: 准确的功耗预测

### 测量内容
| 子系统 | 测量参数 |
|--------|----------|
| CPU | 频率、负载、功耗 |
| 显示屏 | 亮度、功耗 |
| WiFi | 状态、吞吐量、功耗 |
| 蜂窝 | 信号强度、功耗 |
| GPS | 精度、功耗 |

### 关键贡献
- 通用测量方法论
- 多设备验证
- 可重复的实验设计

## 与本研究的关联
- NIST权威的测量方法
- 通用功耗建模框架
- 支持模型验证
