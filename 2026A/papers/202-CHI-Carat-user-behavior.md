# 202. How Carat Affects User Behavior: Implications for Mobile Battery Awareness Applications (ACM CHI)

## 基本信息
- **标题**: How Carat Affects User Behavior: Implications for Mobile Battery Awareness Applications
- **期刊/会议**: ACM CHI 2014
- **年份**: 2014
- **作者**: Kumaripaba Athukorala, Eemil Lagerspetz, Maria von Kügelgen, Antti Jylhä, Adam J. Oliner, Sasu Tarkoma, Giulio Jacucci
- **机构**: University of Helsinki / UC Berkeley
- **链接**: https://amplab.cs.berkeley.edu/wp-content/uploads/2014/06/caratchi.pdf

## 核心内容

### Carat系统
- 大规模移动电池诊断应用
- 识别耗电应用和系统问题
- 提供个性化节能建议

### 用户行为研究
1. **行为改变**: Carat使用后用户行为如何变化
2. **建议采纳率**: 用户是否采纳节能建议
3. **长期效果**: 持续使用的影响

### 主要发现
- 用户倾向于采纳简单的节能建议
- 复杂建议采纳率较低
- 电池意识提升并不总是导致行为改变
