# 155. Mobile Application and Device Power Usage Measurements

## 基本信息
- **标题**: Mobile Application and Device Power Usage Measurements
- **作者**: Rahul Murmuria, Jeffrey Medsger, Angelos Stavrou
- **机构**: George Mason University
- **链接**: https://tsapps.nist.gov/publication/get_pdf.cfm?pub_id=911099
- **来源**: NIST (美国国家标准与技术研究院)

## 研究内容摘要
本文提出了智能手机功耗测量和建模的通用方法论。研究目标是表征设备子系统并进行准确的功耗测量，以支持能耗优化。

## 关键发现
1. **子系统表征**：识别并量化各子系统功耗
2. **测量方法**：提出标准化的功耗测量流程
3. **组件功耗**：
   - CPU: 可变范围最大
   - 屏幕: 随亮度线性变化
   - GPS: 间歇高功耗
   - 无线: 状态依赖
4. **建模框架**：回归模型 vs 状态机模型

## 功耗测量方法
| 方法 | 优点 | 缺点 |
|-----|------|------|
| 外部功率计 | 高精度 | 需硬件 |
| 电池API | 易实现 | 低精度 |
| 软件估算 | 无硬件需求 | 依赖模型 |
| 组件测量 | 可分解 | 复杂 |
