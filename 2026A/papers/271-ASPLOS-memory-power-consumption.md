# 271 - ACM ASPLOS: Memory System Power Consumption

## 基本信息
- **来源**: ACM ASPLOS
- **类型**: 研究
- **主题**: 移动设备内存系统功耗分析

## 核心内容

### 移动内存架构
- **LPDDR**: 低功耗双倍数据率内存
- **LPDDR5**: 最新一代，更高能效
- **容量趋势**: 4GB → 8GB → 12GB → 16GB

### 内存功耗组成
1. **活跃功耗**: 读写操作
2. **刷新功耗**: DRAM周期性刷新
3. **待机功耗**: 数据保持
4. **接口功耗**: 控制器通信

### 功耗特性
| 状态 | LPDDR4 功耗(mW) | LPDDR5 功耗(mW) |
|------|-----------------|-----------------|
| 活跃读 | 400-600 | 350-500 |
| 活跃写 | 350-500 | 300-400 |
| 空闲 | 20-40 | 15-30 |
| 自刷新 | 5-10 | 3-8 |

### 优化策略
- **频率调节**: 根据带宽需求调整
- **深度睡眠**: 降低刷新频率
- **压缩**: 减少数据传输

## 与电池建模相关性

### 内存功耗模型
$$P_{mem} = P_{base} + \alpha \cdot BW + \beta \cdot Capacity$$

- BW: 带宽使用率
- Capacity: 内存容量

### 应用内存行为
- 大内存应用功耗更高
- 后台应用内存占用
- 内存泄漏增加功耗

### 系统级影响
- 内存约占总功耗5-10%
- 多任务场景更显著

## 关键发现
- 内存容量增加导致刷新功耗增加
- LPDDR5比LPDDR4节能约20%
- 应用内存优化可显著节能

## 建模启示
- 内存功耗是系统功耗组成部分
- 需要考虑多任务场景
- 与处理器负载相关
