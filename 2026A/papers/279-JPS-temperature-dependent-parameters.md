# 279 - JPS: Temperature Dependent Battery Parameters

## 基本信息
- **来源**: Journal of Power Sources
- **类型**: 研究
- **主题**: 电池参数的温度依赖性

## 核心内容

### 温度敏感参数
1. **开路电压OCV**: $U_{oc}(SOC, T)$
2. **内阻**: $R(SOC, T, SOH)$
3. **扩散系数**: $D(T)$
4. **容量**: $C(T, I)$

### Arrhenius关系
$$k(T) = k_{ref} \cdot \exp\left[-\frac{E_a}{R}\left(\frac{1}{T} - \frac{1}{T_{ref}}\right)\right]$$

- $E_a$: 活化能 (典型40-60 kJ/mol)
- $k$: 速率常数或参数

### 温度对内阻的影响
| 温度(°C) | R/R_25 | 容量/C_25 |
|----------|--------|-----------|
| -20 | 3.5-4.0 | 0.6-0.7 |
| 0 | 1.8-2.0 | 0.85-0.9 |
| 25 | 1.0 | 1.0 |
| 45 | 0.7-0.8 | 1.0-1.02 |
| 60 | 0.6-0.7 | 0.98-1.0 |

### 温度系数
- **OCV温度系数**: dU/dT ≈ 0.2-0.5 mV/K
- **内阻温度系数**: dR/dT ≈ -1%/K
- **容量温度系数**: dC/dT ≈ 0.5%/K (低温区更敏感)

## 与电池建模相关性

### 参数表示
- 查找表: 2D表(SOC, T)
- 函数拟合: 多项式或Arrhenius
- 混合方法

### 模型实现
```
R(SOC, T) = R_table[SOC_idx][T_idx] 
或
R(SOC, T) = R_ref(SOC) * exp(-Ea/R * (1/T - 1/T_ref))
```

### 验证要求
- 多温度点测试
- 动态温度测试
- 温度估计误差影响

## 建模启示
- 温度是关键影响因素
- 参数温度依赖不可忽略
- 需要充分的温度数据
