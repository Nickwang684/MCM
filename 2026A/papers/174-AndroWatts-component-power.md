# 174. AndroWatts: Unpacking the Power Consumption of Mobile Device's Components

## 基本信息
- **标题**: AndroWatts: Unpacking the Power Consumption of Mobile Device's Components
- **期刊/会议**: HAL / ACM Conference
- **年份**: 2025
- **作者**: Édouard Guégain, Rémy Raes, Noé Chachignot, Clément Quinton, Romain Rouvoy
- **链接**: https://hal.science/hal-04928609

## 核心内容

### 研究创新
- 精细化的组件级功耗分解
- Android平台全面功耗分析工具
- 覆盖所有主要硬件组件

### 分析组件
1. **CPU/GPU**: 计算负载功耗
2. **显示屏**: 亮度和内容相关功耗
3. **相机**: 预览、拍照、录像功耗
4. **音频**: 播放、录音功耗
5. **网络**: WiFi, LTE, 5G功耗
6. **传感器**: 各类传感器功耗

### 关键数据
| 组件 | 空闲功耗 | 典型工作功耗 |
|------|----------|--------------|
| 相机预览 | - | 300-450mW |
| 相机录像 | - | 600-900mW |
| 扬声器 | - | 50-200mW |
| 麦克风 | - | 20-50mW |

### 方法论
- 硬件级功耗测量
- 软件控制变量
- 统计显著性验证

## 与本研究的关联
- 最新的组件级功耗数据
- 全面覆盖智能手机各组件
- 直接支持连续时间功耗建模

`组件功耗` `Android` `相机` `音频` `功耗分解`
