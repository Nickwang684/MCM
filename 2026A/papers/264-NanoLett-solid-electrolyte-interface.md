# 264 - Nano Letters: Solid Electrolyte Interface (SEI)

## 基本信息
- **来源**: Nano Letters
- **类型**: 研究
- **主题**: 锂离子电池SEI层形成与演化

## 核心内容

### SEI层基础
- **定义**: 负极表面与电解质反应形成的钝化层
- **功能**: 阻止电解质持续分解，允许锂离子传输
- **组成**: Li2CO3, LiF, Li2O, 有机锂盐等

### SEI形成机制
1. **初始形成**: 首次充电过程
2. **持续生长**: 日历老化和循环过程
3. **破裂重生**: 体积变化导致

### SEI对性能的影响
- **库仑效率**: 首周效率损失(~10%)
- **阻抗增加**: SEI生长增加内阻
- **容量衰减**: 活性锂消耗

## 与电池建模相关性

### SEI生长模型
- **扩散控制**: 厚度 ∝ √t
- **反应控制**: 厚度 ∝ t
- **混合机制**: 实际情况

### 库仑效率建模
$$CE = \frac{Q_{discharge}}{Q_{charge}} = 1 - \frac{\delta Q_{SEI}}{Q_{charge}}$$

### 日历老化
- SEI持续生长即使不使用
- 温度加速SEI生长
- 高SOC状态下更快

## 关键数据
| 条件 | SEI生长速率 | 容量损失(%/年) |
|------|------------|----------------|
| 25°C, 50%SOC | 低 | 2-3% |
| 25°C, 100%SOC | 中 | 4-5% |
| 45°C, 50%SOC | 高 | 6-8% |
| 45°C, 100%SOC | 很高 | 10-12% |

## 建模启示
- SEI是日历老化的主要机制
- 需要考虑温度和SOC的影响
- 连续时间模型应包含SEI生长动力学
