\section{Sensitivity Analysis}
\label{sec:sensitivity}

We employ Sobol variance-based global sensitivity analysis to identify the key parameters influencing battery life predictions. The output variable is time-to-empty $t_{empty}$ [hours], defined as the time for SOC to decrease from initial value to 10\% cutoff.

\subsection{Methodology}

Using Saltelli's sampling scheme with $N=128$ base samples (2,560 model evaluations), we compute:
\begin{itemize}
    \item \textbf{First-order index} $S_1$: Main effect of parameter $X_i$, given by $S_{1,i} = V[E(Y|X_i)]/V(Y)$
    \item \textbf{Total-order index} $S_T$: Main effect plus all interactions, given by $S_{T,i} = 1 - V[E(Y|X_{\sim i})]/V(Y)$
\end{itemize}

\subsection{Key Findings}

\begin{enumerate}
    \item \textbf{Initial SOC dominates} ($S_T=0.710$): Starting charge accounts for $>$70\% of output variance.
    
    \item \textbf{CPU Utilization is the primary controllable factor} ($S_T=0.389$): A 30\% reduction in CPU load extends battery life by 42.5\%.
    
    \item \textbf{Screen brightness has moderate impact} ($S_T=0.077$): Dimming from max to 50\% yields $\sim$18\% improvement.
    
    \item \textbf{Temperature effects are negligible} ($S_T<0.01$): The model is robust within 0--40$^\circ$C.
    
    \item \textbf{Extreme scenario range}: Battery life varies \textbf{6.8$\times$} between best case (22.5h: light usage, fresh battery) and worst case (3.3h: heavy usage, degraded battery).
\end{enumerate}

\subsection{Recommendations}

\textbf{For Users:} (1) Reduce background CPU processes; (2) Use adaptive brightness; (3) Enable GPS only when needed.

\textbf{For Designers:} Prioritize CPU power efficiency; implement intelligent display dimming; focus testing on usage patterns rather than environmental extremes.
